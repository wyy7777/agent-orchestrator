## 架构

```
┌─────────────────────────────────────────┐
│          前端 (Next.js 静态文件)          │
│   Dashboard │ 工作流 │ 任务 │ 审批       │
└────────────────────┬────────────────────┘
                     │ HTTP / WebSocket
┌────────────────────┴────────────────────┐
│         FastAPI 后端 (单进程)             │
│                                         │
│  REST API ── WebSocket ── 状态机引擎     │
│       │                     │           │
│       └── 步骤处理器 ───────┘           │
│           (analyze/execute/review)       │
│                  │                       │
│           AI 代理层                       │
│       DeepSeek / OpenAI / Claude         │
│                  │                       │
│           SQLite 数据库                   │
│                                         │
│  GitHub 集成模块                          │
│  (仓库连接 │ Webhook 处理 │ PR 审查)     │
└─────────────────────────────────────────┘
        ▲                         │
        │  REST API / Webhook     │ 代码审查结果推送
        │                         ▼
     GitHub 仓库              AI 代理层 (虚线流)
```

*图例: 实线箭头=API/Webhook通信，虚线箭头=代码审查结果推送*
