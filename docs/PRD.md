# 产品需求文档 (PRD)

## 一、痛点分析

### 1.1 不可靠 — 同一条指令两次结果天差地别

| 场景 | 表现 |
|------|------|
| 同一 issue → Agent 修复 | 第一次成功，第二次跑偏，第三次超时 |
| Token 消耗不可控 | 复杂任务可能烧掉 200 万 tokens 后无结果 |
| 输出质量不稳定 | 有时生产级代码，有时带明显 bug |

### 1.2 不可控 — Agent 越权操作

| 场景 | 表现 |
|------|------|
| "优化数据库查询" | Agent drop 了一张表 |
| "重构代码" | 改了 47 个文件，12 个不在计划内 |
| "修一个 bug" | Agent 顺带重构了整个模块 |

### 1.3 不可审计 — 出问题无法追溯

| 场景 | 表现 |
|------|------|
| 生产事故 | "Agent 执行了哪个 commit？谁批准的？"——不知道 |
| 合规要求 | 金融/医疗行业需要审计 Agent 的每一步决策 |
| 团队协作 | 多个 Agent 交替执行，不知道哪一步引入的问题 |

## 二、目标用户

### 早期用户画像

| 角色 | 痛点 | 动机 |
|------|------|------|
| **技术 TL/VP Eng** | 想推 AI 提效但不敢让 Agent 碰生产代码 | 需要一个"安全网" |
| **DevOps/SRE** | 担心 Agent 自主动作打出生产事故 | 需要审批和回滚 |
| **安全/合规负责人** | Agent 操作没留痕，审计过不了 | 需要全链路日志 |
| **开源项目维护者** | 想用 Agent 自动 triage issue / review PR | 需要可信的结果 |

### 后续扩展

| 角色 | 场景 |
|------|------|
| 数据工程师 | Agent 自动修复数据 pipeline |
| QA 工程师 | Agent 自动生成并执行测试用例 |
| 技术支持 | Agent 自动诊断并修复客户问题 |

## 三、用户故事

### US-1: 可审批的 Agent 工作流

> 作为技术 TL，我定义了一个 "Bug 修复工作流"，要求 Agent 在写代码和发 PR 两个节点必须我审批后才能继续。

```
触发：GitHub Issue 标记 "agent-fix"
  ↓
Step 1: 分析 — Agent 读取 issue + 代码，生成修复方案 → 自动通过
  ↓
Step 2: 审批 — 展示方案，等待我点"批准"或"拒绝" → 人工决策
  ↓
Step 3: 执行 — Agent 在隔离分支修改代码 → 自动通过
  ↓
Step 4: 审查 — AI 自审 diff，生成 review 报告 → 自动通过
  ↓
Step 5: 审批 — 展示改动 + 审查报告，等待最终确认 → 人工决策
  ↓
Step 6: 合并 — 创建 PR 并合并到主分支 → 自动通过
```

### US-2: 一键回滚

> Agent 执行到第 4 步时我发现方向不对，点击"回滚到第 2 步"，所有中间改动被撤销，Agent 从第 2 步重新开始。

### US-3: 执行审计

> 审计要求查看过去 30 天所有 Agent 操作的日志。我可以按时间/项目/操作人筛选，看到每一步的输入、输出、token 消耗、审批记录。

### US-4: 质量仪表盘

> 我打开仪表盘，看到团队过去一周 Agent 执行了 127 次任务，成功 89 次（70%），平均审批通过率 62%。我还看到最常见失败原因是"方案不符合预期"。

### US-5: 工作流模板

> 我不需要从零定义工作流。从社区模板库选择了"GitHub Issue 自动修复"，稍作修改就用上了。

## 四、功能列表

### P0 — MVP 必备 (6-8 周)

| 功能 | 说明 |
|------|------|
| YAML 工作流定义 | 可视化或代码定义多步任务 |
| 基础步骤类型 | analyze / execute / review / merge |
| 审批节点 | 指定步骤暂停，等待人工确认 |
| Git 沙箱 | 在临时分支执行，不影响主分支 |
| PR 创建 | 自动生成 PR |
| 执行日志 | 每步输入/输出/token/timing |
| Web Dashboard | 查看/管理任务 |

### P1 — V1.0 (后续 4-6 周)

| 功能 | 说明 |
|------|------|
| 回滚/重试 | 一键回退到任意步骤 |
| 工作流模板 | GitHub Issue Fix / PR Review / Refactor 等 |
| Slack/钉钉通知 | 审批节点推送通知 |
| Token 限额 | 设置每任务最大 token 消耗 |
| 质量评分 | AI 自动评估 diff 质量 |
| 时间线视图 | 可视化每个任务的执行甘特图 |

### P2 — V1.5+

| 功能 | 说明 |
|------|------|
| 多 Agent 协作 | 不同 Agent 负责不同步骤 |
| 条件分支 | 根据执行结果动态选择后续步骤 |
| 定时触发 | Cron 触发周期性任务 |
| SSO/LDAP | 企业身份集成 |
| 私有部署 | On-premise / VPC 部署 |
| 合规报告 | 一键生成审计报告 |
