## 竞品详细对比

### 1. LangSmith (LangChain)

| 维度 | 评价 |
|------|------|
| 定位 | LLM 应用的可观测性平台 |
| 优势 | 强大的 tracing、监控、评估能力 |
| 弱点 | 偏向监控，不提供审批流/编排/回滚；依赖 LangChain 生态 |
| 差异化 | **我们做的是"执行控制层"，LangSmith 做的是"观测层"** |

### 2. CrewAI / AutoGen

| 维度 | 评价 |
|------|------|
| 定位 | 多 Agent 协作框架 |
| 优势 | 灵活的角色定义、任务分配 |
| 弱点 | 偏研究/实验性质；执行结果不可复现；无审批/回滚；无企业特性 |
| 差异化 | **框架 vs. 平台：框架关注"Agent 怎么做"，我们关注"Agent 做得对不对"** |

### 3. Devin (Cognition)

| 维度 | 评价 |
|------|------|
| 定位 | AI 软件工程师（端到端） |
| 优势 | 全自动完成任务，震撼的 Demo |
| 弱点 | 黑盒不可控；企业不敢用；贵（$500/月）；不能定义工作流 |
| 差异化 | **Devin 是全自动黑盒，我们是半自动白盒 — 企业选后者** |

### 4. GitHub Copilot Workspace

| 维度 | 评价 |
|------|------|
| 定位 | AI 辅助开发工作区 |
| 优势 | 深度集成 GitHub，从 Issue 到 PR |
| 弱点 | 偏向个人开发体验；无审批/审计；不能自定义工作流 |
| 差异化 | **Copilot Workspace 是个人工具，我们是团队平台** |

### 5. Weights & Biases (W&B Prompts)

| 维度 | 评价 |
|------|------|
| 定位 | ML 实验追踪 + LLM 评测 |
| 优势 | 强大的跟踪和可视化 |
| 弱点 | 偏 ML 训练和评估场景；不涉及 Agent 执行控制 |
| 差异化 | **不同赛道：W&B 关注"模型好不好"，我们关注"Agent 靠不靠谱"** |

### 6. Temporal (编排引擎本身)

| 维度 | 评价 |
|------|------|
| 定位 | 通用工作流编排引擎 |
| 优势 | 生产级可靠性、多语言 SDK |
| 弱点 | 不是 AI 产品，需要自己搭建 Agent 集成层 |
| 差异化 | **Temporal 是我们的基础设施，不是竞品** |

---

## 核心差异化总结

| 我们 | 别人 |
|------|------|
| Agent 执行**可控**（审批/回滚/沙箱） | Agent 执行**不可控**（黑盒/全自动） |
| **面向团队**（审批流、审计、仪表盘） | **面向个人**（IDE 插件、聊天界面） |
| **工作流可定义**（YAML/可视化编辑器） | **行为不可定义**（Agent 自己决定） |
| **白盒**：每一步可见可审 | **黑盒**：像魔法一样出结果 |
| 基础设施复用 Temporal | 自研编排引擎或没有编排 |

## 竞品威胁矩阵

| 威胁等级 | 来源 | 场景 | 防御 |
|----------|------|------|------|
| 🔴 高 | GitHub/GitLab 官方做审批 Agent | 平台自带能力 | 快跑，先占领心智；深度差异化（行业模板、合规报告） |
| 🟠 中 | Devin 推出企业版（带审批） | 功能趋同 | 强调开放/可定制 vs. Devin 黑盒 |
| 🟡 低 | LangSmith 增加编排功能 | 功能扩张 | 不同赛道根基，我们更偏执行控制 |
| 🟢 极低 | CrewAI 做成平台 | 团队基因不匹配 | 框架思维 vs. 产品思维 |
