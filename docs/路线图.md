# 开发路线图

## 概览

```
Phase 1 ──────── Phase 2 ──────── Phase 3 ──────── Phase 4
MVP (6周)       V1.0 (6周)       V1.5 (8周)       企业版 (持续)
开源单机         团队协作          平台化             私有部署
```

---

## Phase 1: MVP — 开源单机版 (Week 1-6)

> 目标：一个开发者能本地运行，定义工作流 → Agent 执行 → 审批 → PR

### Milestone 1: 基础骨架 (Week 1)

- [ ] 项目脚手架搭建
- [ ] 数据库 Schema
- [ ] YAML 工作流解析器
- [ ] 工作流 CRUD API
- [ ] 前端 Dashboard 框架

### Milestone 2: 执行引擎 (Week 2)

- [ ] Temporal 集成
- [ ] 状态机驱动的步骤执行
- [ ] 手动审批步骤
- [ ] 执行日志记录

### Milestone 3: AI 集成 (Week 3-4)

- [ ] Claude API / OpenAI API 封装
- [ ] Analyze 步骤实现
- [ ] Execute 步骤实现
- [ ] Review 步骤实现
- [ ] Prompt 模板系统

### Milestone 4: Git 沙箱 (Week 4-5)

- [ ] Docker 沙箱管理
- [ ] Git 操作封装
- [ ] PR 自动创建
- [ ] 沙箱生命周期管理

### Milestone 5: 审批 & 回滚 (Week 5)

- [ ] 审批面板
- [ ] 通知机制
- [ ] 回滚功能
- [ ] Token 限额

### Milestone 6: 发布 (Week 6)

- [ ] Dashboard 可视化
- [ ] 文档 & Landing Page
- [ ] 开源发布 (GitHub)
- [ ] Show HN / Product Hunt

---

## Phase 2: V1.0 — 团队协作 (Week 7-12)

- [ ] 多用户/团队支持
- [ ] 工作流模板库
- [ ] Slack/钉钉集成
- [ ] 高级审批规则（谁可以审批什么）
- [ ] 质量评分系统
- [ ] 执行历史搜索
- [ ] GitHub App 集成（直接通过 GitHub marketplace 安装）

---

## Phase 3: V1.5 — 平台化 (Week 13-20)

- [ ] 条件分支（根据执行结果动态选择步骤）
- [ ] 多 Agent 协作
- [ ] 定时触发 (Cron)
- [ ] Webhook 触发器
- [ ] 自定义步骤类型（插件系统）
- [ ] 第三方集成市场
- [ ] 高级分析仪表盘

---

## Phase 4: 企业版 (持续)

- [ ] SSO / LDAP / SAML
- [ ] RBAC 权限控制
- [ ] 私有化部署方案
- [ ] VPC 部署
- [ ] 合规审计报告（SOC2、GDPR、EU AI Act）
- [ ] SLA 保证
- [ ] 专属客服

---

## 关键决策节点

| 时间 | 决策 | 条件 |
|------|------|------|
| Week 8 | 是否全职投入 | 开源项目 Star > 500, 社区活跃 |
| Week 16 | 是否融资 | 付费客户 > 20, MRR > $5K |
| Month 12 | 是否开始企业销售 | 产品成熟, 有 3+ 企业设计合作伙伴 |

## 资源需求

| 阶段 | 人员 | 预算/月 |
|------|------|---------|
| Phase 1 | 2 人 (全栈 + 设计/兼职) | $5K (基础设施 + API) |
| Phase 2 | 3-4 人 (2 全栈 + 1 前端 + 0.5 设计) | $25K |
| Phase 3 | 5-6 人 (+ 社区经理 + 初级 Dev) | $50K |
| Phase 4 | 8+ 人 (+ Sales + Support) | $100K+ |
