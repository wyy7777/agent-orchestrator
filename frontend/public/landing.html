为什么选择 Agent Orchestrator？

🛡️

人工审批门控

关键步骤暂停等待人工审批，防止 AI 失控。支持任意步骤插入审批节点。

📋

YAML 工作流

声明式定义多步骤 AI 工作流，支持并行执行、条件分支、循环、子任务。

🔄

一键回滚

出问题可回退到任意已完成步骤，保证代码安全。

🤖

多模型支持

DeepSeek / OpenAI / Claude 自由切换，自动重试和超时处理。

🔌

插件系统

HTTP 请求、Shell 命令、数据转换等内置插件，支持自定义扩展。

📊

实时监控

WebSocket 实时推送任务状态，Dashboard 可视化执行统计。

如何使用？

1

定义工作流

用 YAML 定义分析、执行、审查等步骤

2

触发执行

手动触发、Webhook 或定时任务

3

AI 执行

Agent 自动分析代码、生成修复方案

4

人工审批

关键节点暂停，你来决定是否继续

5

自动合并

审批通过后自动创建 GitHub PR
